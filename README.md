# Improved File Security System Using Multiple Image Steganography

This project implements a secure file transmission system using Image Steganography with the Pixel Value Differencing (PVD) algorithm.

## Features
- Hide secret text inside multiple images
- Uses PVD based steganography
- Extract hidden message from encoded images
- Simple GUI using Tkinter

## Technologies Used
- Python
- OpenCV
- Pillow
- NumPy
- Tkinter

## Installation

Install dependencies:

pip install -r requirements.txt

## Run the Project

python Main.py

## Workflow
1. Upload image folder
2. Upload text file
3. Text gets sliced and embedded in images
4. Encoded images stored in Encoded_Images folder
5. Extract text using decoding option
